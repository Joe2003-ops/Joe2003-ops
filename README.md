## About Me

I'm **Joe Ngururi Nguno**, a Data Science and Software Engineering professional based in Nairobi, Kenya.

I enjoy building practical solutions that bridge raw data analysis, machine learning, backend systems, and real-time observability. My interests include time-series forecasting, intelligent applications, systems programming, and AI-driven security.

I work across the full development process—from exploring and preparing data to training models and building applications that make analytical results useful.

- **Data Science:** Data preprocessing, exploratory analysis, machine learning, and forecasting.
- **Applied AI:** Retrieval-Augmented Generation (RAG), embeddings, and graph neural networks.
- **Software Engineering:** Backend APIs, concurrent CLI applications, and memory-conscious C++ development.
- **Visualization:** Interactive dashboards, geospatial analysis, and data storytelling.
- **Developer Tools:** Docker, development containers, Git, GitHub Actions, and reproducible workflows.

**Currently interested in:** practical AI systems, forecasting, environmental analytics, and efficient software architectures.

## Featured Projects

### 1. Country-Level CO₂ Emissions Forecaster

A time-series forecasting project designed to explore country-level carbon emissions and support scenario analysis.

- Combines **Prophet** forecasting with **Ridge Regression** in a two-stage modeling approach.
- Provides an interactive **Streamlit** interface for exploring forecast scenarios.
- Connects data analysis and machine learning with environmental decision support.

**Technologies:** Python, Pandas, Scikit-learn, Prophet, Streamlit.

### 2. EcoSort Waste Management Assistant

An AI-assisted waste management and policy information system built around Retrieval-Augmented Generation (RAG).

- Uses custom document chunking and embeddings.
- Retrieves relevant policy and classification information from source documents.
- Organizes retrieved context to support more grounded responses.

**Technologies:** Python, RAG, embeddings, document retrieval.

### 3. AI Security Observability & Graph Neural Networks

Research into monitoring software execution and identifying potential threats using graph-based machine learning.

- Explores **PyTorch Geometric** for graph neural network workflows.
- Investigates real-time execution monitoring and threat prevention.
- Considers **ONNX** and **TensorRT** for runtime optimization.

**Technologies:** Python, PyTorch Geometric, ONNX, TensorRT.

### 4. Spatial & Public Health Analytics

Geospatial and time-series analysis focused on outbreak readiness and epidemiological trends.

- Uses spatial data to explore geographic patterns.
- Applies mapping and visualization to communicate public health trends.
- Combines geospatial analysis with exploratory data analysis.

**Technologies:** Python, GeoPandas, Folium, Seaborn, Pandas.
